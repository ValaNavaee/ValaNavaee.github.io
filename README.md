# Vala Navaeenia — Portfolio

Personal portfolio site for Vala Navaeenia, environment concept artist and
visual development artist based in Istanbul.

## Structure

- `index.html` — the page
- `styles.css` — all styles
- `assets/img/` — compressed web copies of the artwork

## Running locally

No build step. Serve the folder with any static server, e.g.:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Deploying

Static HTML/CSS only — works on GitHub Pages, Netlify, Vercel, or any static host.
